# BUG-004: Slow Navigation and Response Time with Performance Glitch User

**Application:** SauceDemo  
**Test User:** performance_glitch_user  
**Testing Type:** Manual Testing  
**Severity:** Minor (provisional)  
**Priority:** Medium (provisional)  
**Status:** Open / Observation

## Description

Noticeable delays are observed during multiple navigation actions and shopping flow operations while testing with `performance_glitch_user`.

## Preconditions

- User is logged in using `performance_glitch_user`.
- Password is `secret_sauce`.

## Steps to Reproduce

1. Open https://www.saucedemo.com/
2. Login using `performance_glitch_user` and `secret_sauce`.
3. Observe the time taken for the inventory page to open.
4. Click any product name and observe the time taken to open the product details page.
5. Click Back to Products and observe the return navigation.
6. Add a product to the cart and click Continue Shopping.
7. Proceed to checkout, enter the required information and click Cancel.
8. Complete an order and click Back Home.
9. Observe the response time for these actions.

## Expected Result

Navigation and shopping flow actions should respond within a reasonable time and provide a smooth user experience.

## Actual Result

Noticeable delays occur when:

- Opening the inventory page after login.
- Opening product details.
- Returning to the inventory page.
- Clicking Continue Shopping from the cart.
- Clicking Cancel during checkout.
- Clicking Back Home after completing an order.

## Notes

Observed specifically while testing the `performance_glitch_user` account. This account is intended to simulate performance-related delays in SauceDemo. This report documents the observed behavior for the assignment and should be distinguished from an unexpected defect affecting the standard user.
