# BUG-003: Cart Action Buttons Become Unresponsive

**Application:** SauceDemo  
**Test User:** problem_user  
**Testing Type:** Manual Testing  
**Severity:** Major  
**Priority:** High  
**Status:** Open

## Description

While adding multiple products to the cart using the `problem_user` account, cart-related buttons become unresponsive and prevent further interactions.

## Preconditions

- User is logged in as `problem_user`.
- Inventory page is displayed.

## Steps to Reproduce

1. Open https://www.saucedemo.com/
2. Login using `problem_user` and `secret_sauce`.
3. Add Sauce Labs Backpack to the cart.
4. Add Sauce Labs Bike Light to the cart.
5. Add Sauce Labs Onesie to the cart.
6. Attempt to add another product or interact with the affected cart buttons.
7. Observe the button behavior.
8. Try to continue shopping or remove items if the buttons are affected.

## Expected Result

Add to Cart, Remove, Continue Shopping and other cart-related buttons should respond correctly to user actions. The cart count and cart contents should update accordingly.

## Actual Result

After adding multiple products, some cart-related buttons become unresponsive. Further interactions cannot be completed as expected.
